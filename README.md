# Statistics and Probability for Machine Learning Challenge

This project demonstrates how changing numerical values in a dataset affects statistical analysis results using Python.

## Tools Used
- Python
- Pandas
- SciPy
- Statsmodels
- Visual Studio Code

## Challenge
I modified numerical values in `column_1` and `column_2` twice while keeping the other columns unchanged.

After each modification, I ran the Python script to compare the statistical results.

## Analysis Performed
- Descriptive Statistics
- Probability Calculation
- Hypothesis Testing
- Correlation Analysis
- Regression Analysis

## Observations
Changing numerical values affected the statistical calculations, including averages, correlations, and regression results.

The probability of `target = 1` remained at 73.33% because the target values were not modified.

## Conclusion
This challenge helped me understand how changes in data affect statistical analysis and why accurate data is important in machine learning.
